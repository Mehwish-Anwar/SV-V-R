| **State ID** | **State Name**        | **Description – What is the robot doing?**                          | **Entry Condition – When does it enter this state?**      | **Exit Condition – When does it leave this state?**                             |
| ------------ | --------------------- | ------------------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **S1**       | **IDLE**              | The robot is doing nothing. It is waiting for a new delivery order. | The robot starts or comes back to the warehouse.          | When the robot gets a new delivery order.                                       |
| **S2**       | **NAVIGATING**        | The robot is going to the delivery place.                           | When the robot gets a delivery order.                     | When it reaches the destination, finds an obstacle, or the battery is very low. |
| **S3**       | **AVOIDING_OBSTACLE** | The robot is avoiding an obstacle in its way.                       | When the robot finds an obstacle while moving.            | When the robot successfully avoids the obstacle.                                |
| **S4**       | **DELIVERING**        | The robot is giving the package to the customer.                    | When the robot reaches the delivery destination.          | When the package is successfully delivered.                                     |
| **S5**       | **RETURNING**         | The robot is going back to the warehouse after delivery.            | When the package is delivered or the battery is very low. | When the robot reaches the warehouse.                                           |
